Routing practice

The employee ID comes from the :id path parameter, and mode comes from the query string. The employee is loaded by the route resolver and read from ActivatedRoute.data. In edit mode, changing the name marks it unsaved so CanDeactivate can ask before leaving.

BehaviorSubject practice: saving publishes the updated employee through EmployeeService. The Employees page receives the latest list from the same BehaviorSubject when you return.

Resolver data flow

  1. Employees page employees-component.html navigates to /employees/7
  2. ↓
  3. Route configuration app.routes.ts matches employees/:id and runs employeeResolver
  4. ↓
  5. Resolver employee.resolver.ts reads the ID and calls EmployeeService.getEmployeeById(id)
  6. ↓
  7. Service employee.service.ts returns the employee after a simulated delay
  8. ↓
  9. Details component and template employee-details-component.ts reads data['employee']; this HTML displays the resolved employee
