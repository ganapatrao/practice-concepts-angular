Angular practice scenarios

What we have practiced

This page summarizes the mock login, role selection, navigation, and route protection scenarios in this app.

1. Choose a practice role at login

The login form has an admin checkbox and a template-driven-form practice checkbox. Selecting template practice stores the template-practice role; otherwise, the admin checkbox chooses between admin and employee.

2. Save the mock login state

Submitting the mock login stores isLoggedIn and role in localStorage. The current-user service reads the saved role when the app starts and publishes role changes to the layout.

3. Navigate according to the selected role

Template-practice users are sent to the template-driven form page and see that page plus this summary in the menu. Admin and employee users keep the existing dashboard, employees, and leave-request links, and can also open this summary.

4. Protect routes with a guard

The authentication guard sends logged-out visitors to login. The child-route guard keeps template-practice users on their practice page, while allowing every logged-in role to visit this summary page.

These roles and guards are for learning only. A role stored in localStorage can be changed in the browser, so it is not suitable for real authorization.
