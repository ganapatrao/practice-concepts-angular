Routing practice

@for creates a row for each employee. View uses routerLink to pass the employee ID as a path parameter and mode=view as a query parameter. Edit passes the ID to router.navigate() with mode=edit. The details route resolves the employee before displaying that page. Delete is a visual placeholder.
