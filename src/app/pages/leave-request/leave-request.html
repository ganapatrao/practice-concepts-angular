Routing practice

The title and instructions come from static route data via ActivatedRoute.data. This template-driven form uses ngForm and ngModel; editing a field marks it unsaved, and the route's CanDeactivate guard checks that flag when you navigate away.

Subject practice: submitting emits a notification from this page through NotificationService. The Layout component receives and displays that event.
